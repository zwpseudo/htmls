How to Manage All Events: View, Create & Copy

Locate the "All Events" Dashboard

 

  1. Make sure you are logged in to Eventeny. From the homepage, hover over the "Organize" tab and select the "See all events" button.  


     

  2. You’ll be taken to the All Events dashboard. This is the central hub where you can search, filter, and manage events tied to your account. At the top of the page, you’ll see:
     

    1. Company Selector: If your account is connected to more than one company or organization, you can use the dropdown menu to switch between them. Simply select the company you want to work with to view its events.



       

    2. Search Bar: Quickly find a specific event by typing in the event name. This is especially useful if you have many events listed under your account.


       

     

View Upcoming Events

 

  1. Next, you'll see the Upcoming Events tab. This section displays all events that are scheduled to happen in the future. Each event is shown as an event card with key details and management options:



     

    • Event Name & Cover Photo: The name and visual banner of the event.
       

    • Date & Time: When the event is scheduled to begin and end.
       

    • Event Status: Shows whether the event is active and scheduled.
       

    • Publish Status: Indicates if the event is live (Published) or still in setup (Draft).
       

    • Preview Event: Allows you to see what the event page looks like before or after publishing.
       

    • Manage Button: Opens the event’s management page, where you can edit event details, tickets, vendors, and more. To make changes to any event, simply click Manage on the corresponding event card.

 

View Past Events

 

  1. Next to the Upcoming Events tab, you’ll find the All Events tab. This section lists every event you’ve created, whether it’s upcoming, currently ongoing, or already completed.  This tab is especially helpful for referencing past events, reusing event setups, or checking on the status of ongoing events. Each event in this list view includes:


     

    • Event Name & Thumbnail Image: A quick way to identify the event.
       

    • Date & Time: The full range of when the event took place (or is scheduled to take place).
       

    • Status Label: 
       

      1. Ongoing: Events currently active.

      2. Past: Events that have already ended.
         

    • Preview Event Link: Allows you to review the event page, even if it’s already finished.

If an event has already ended, do not edit the original details. This may confuse your records. Instead, use the Copy from Event option or the Create a New Event button to build a new event based on the past one.

 

Create A New Event 

 

  1. From the All Events dashboard, you have two quick ways to start creating a new event. You can use the "Create A New Event" button located at the top right of the dashboard or the "Create A New Event" button in the Upcoming Events tab. Clicking either button will begin the event creation process. To learn more about the event creation process, review this guide. 




     

     

Copy From An Existing Event

 

  1. In addition to starting from scratch, you can also create a new event by copying the template of an existing event. From the Upcoming Events tab, you’ll see a Copy from Event button at the top right of the page. 


     

  2. Clicking this option allows you to duplicate an event you’ve previously created. The new event will copy over important details such as structure, layout, and settings, so you don’t have to rebuild everything from the ground up. You can then update the event name, dates, and any other information to match your new event. To learn more about duplicating an event, use this guide.
