Add Conversion Elements

  1. Before connecting your Google Tag Manager with Eventeny, you will need to create & publish the elements to your Eventeny event that you want to track conversions and interactions for.

    The integration between Eventeny and Google Tag manager currently supports tracking for the following elements. Click on each to learn more about how to set them up:

      • Tickets
      • Artist, vendor, and exhibitor applications 
      • Volunteer applications
      • Sponsor applications
      • Other applications 

 

Publish the Event

  1. To successfully connect Eventeny with Google Tag Manager, your event must first be published. Before publishing, double-check that all of your tickets and applications are set to “Live.”

    On your event dashboard, you should see two big red buttons at the bottom left and right of your screen that says, "Publish Event" or "⚠ Publish Event to Eventeny."

    When you are ready, go ahead and click that button! Learn more about publishing your event here. 



 

Add Google Tag Manager ID 

 

  1. Scroll down the left sidebar menu of your event dashboard until you reach "Other actions," the second-to-last tab above "Preview." Click the dropdown and choose "Settings."



  2. To integrate, click the "✎ edit" button on the right, enter your Google Tag Manager ID, then click "✔ Save" when done.






Setting Up Google Tag Manager

 

 
Eventeny customer support cannot assist with the setup or management of external tools like Google Tag Manager. Custom code is not supported through the standard integration. If you need to use a custom snippet, please contact support@eventeny.com for review and potential manual placement by our engineering team. For detailed setup instructions, visit Google’s Help Center.
