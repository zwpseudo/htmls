Before You Begin

 

This article requires that you’ve already created both a map and an application for your event. You’ll need to have at least one of the following applications set up:
 

  • Artist, Vendor, or Exhibitor Application

  • Sponsor Application

  • Other Application


If you haven’t created these yet, please review the following guides first:

  • How to Create a Map

  • How to Create an Artist, Vendor, or Exhibitor Application

  • How to Create a Sponsor Application

  • How to Create an “Other” Application


Once your map and at least one application are created, you’ll be ready to proceed with the steps in this article. You can also complete this setup during the application creation process if you’ve already built your map. 

 

Navigate To Your Desired Event

 

  1. Make sure you are logged into Eventeny.
     
  2. At the top of the home page, hover over the "Organize" tab and select the event you wish to work with.

 

Connect To An Artist, Vendor, or Exhibitor Application

 

  1. From the "Artists, Vendors & Exhibitors" tab, select the "Applications" option. 


     
  2. Click on the "Edit application" button on the application card that you wish to connect to the map. 


     
  3. Click on the pencil icon to begin editing the application.


     

  4. Scroll down to the Map section. You’ll see a list of maps that you’ve created and published. Select the map you want to connect to this specific application.
     

    If you don’t see your map listed, return to your Maps tab and make sure the map is published or set to “Live.” Only published maps will appear as options in the selection menu.



     

  5. Once you are done selecting the desired map, scroll back up to the top of the application editor and select the "Save" to finalize your changes. 



     

Connect To A Sponsor Application 

 

  1. From the "Sponsors" tab, select the "Applications" option. 


     
  2. Click on the "Edit application" button on the application card that you wish to connect to the map. 


     
  3. Click on the pencil icon to begin editing the application.


     

  4. Scroll down to the Map section. You’ll see a list of maps that you’ve created and published. Select the map you want to connect to this specific application.
     

    If you don’t see your map listed, return to your Maps tab and make sure the map is published or set to “Live.” Only published maps will appear as options in the selection menu.



     

  5. Once you are done selecting the desired map, scroll back up to the top of the application editor and select the "Save" to finalize your changes. 


 

 

Connect To An "Other" Application

 

  1. From the "Other Applications" tab, select the "Applications" option. 


     
  2. Click on the "Edit application" button on the application card that you wish to connect to the map. 


     
  3. Click on the pencil icon to begin editing the application.


     

  4. Scroll down to the Map section. You’ll see a list of maps that you’ve created and published. Select the map you want to connect to this specific application.
     

    If you don’t see your map listed, return to your Maps tab and make sure the map is published or set to “Live.” Only published maps will appear as options in the selection menu.



     

  5. Once you are done selecting the desired map, scroll back up to the top of the application editor and select the "Save" to finalize your changes.
